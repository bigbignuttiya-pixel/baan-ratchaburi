# บ้านราชบุรี

เว็บไซต์โปรเจกต์บ้านพักอาศัย 2 ชั้น ต.หน้าเมือง อ.เมือง จ.ราชบุรี

- `index.html` — หน้าเว็บไซต์ (ภาพเรนเดอร์ วิดีโอ ผังบ้าน สเปก การแก้แบบ)
- `studio.html` — โมเดล 3D แบบอินเทอร์แอคทีฟ (WebGL2)
- `img/` ภาพเรนเดอร์ · `house_360.mp4`, `house_tour.mp4` วิดีโอ

เว็บแบบ static ไม่ต้อง build — Vercel: Framework Preset = Other, Output Directory = `.`
